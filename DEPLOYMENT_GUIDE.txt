================================================================================
                     OPTION 1: 000WEBHOST (RECOMMENDED)
================================================================================

STEP 1: Create Account
-----------------------
1. Go to: https://000webhostapp.com
2. Click "Sign Up"
3. Choose: "I want to build a website"
4. Select: "PHP Website" (free)
5. Sign up with email or Google account
6. Verify your email

STEP 2: Create Website
-----------------------
1. After login, click "Create new site"
2. Enter your site name: ephrem-tadewos
3. Your URL will be: https://ephrem-tadewos.000webhostapp.com

STEP 3: Upload Files
---------------------
1. In 000webhost panel, go to "File Manager"
2. Click "public_html" folder
3. Delete all default files (except .htaccess)
4. Click "Upload" button
5. Upload ALL files from your proj folder:
   - index.php, home.php, register.php
   - contact.php, admin.php, logout.php
   - setup.php, config.php, style.css
   - (Upload each file or zip and extract)

STEP 4: Setup Database
----------------------
1. In panel, go to "Databases" > "MySQL"
2. Create database:
   - Database name: portfolio
   - Username: root (or your created user)
   - Password: (leave empty or create one)
3. Note down: Database name, User, Password

STEP 5: Edit Config
-------------------
1. Go to File Manager > public_html
2. Edit config.php:
   - Change password to your MySQL password
   - If username is not root, change it too
3. Save file

STEP 6: Run Setup
-----------------
1. Visit: https://your-site.000webhostapp.com/setup.php
2. You should see "Setup Complete!"

STEP 7: Your Site is LIVE!
--------------------------
- Main site: https://ephrem-tadewos.000webhostapp.com
- Login: https://ephrem-tadewos.000webhostapp.com/index.php
- Register: https://ephrem-tadewos.000webhostapp.com/register.php

================================================================================
                     CONFIG.PHP EDITING
================================================================================

Before uploading, edit config.php with your hosting credentials:

BEFORE (Localhost):
-------------------
$servername = "localhost";
$username   = "root";
$password   = "";
$dbname     = "portfolio";

AFTER (000webhost):
--------------------
$servername = "localhost";
$username   = "your_db_username";   // Check your hosting panel
$password   = "your_db_password";   // Check your hosting panel  
$dbname     = "your_db_name";       // Usually same as username_xxx

================================================================================
                     HOW TO TEST BEFORE GOING LIVE
================================================================================

1. XAMPP Test (local):
   - Start Apache & MySQL in XAMPP
   - Go to http://localhost/proj/
   - Run setup.php first
   - Test registration/login

2. If errors appear:
   - Check config.php database credentials
   - Make sure database was created
   - Check PHP version (need PHP 7+)

================================================================================
                     COMMON ISSUES & FIXES
================================================================================

Issue: "Cannot connect to database"
Fix: Update config.php with correct DB credentials from hosting

Issue: "Table doesn't exist"  
Fix: Run setup.php on your live site

Issue: "Session errors"
Fix: Already fixed - use new config.php

Issue: "404 errors on pages"
Fix: Make sure .htaccess allows PHP routing (already configured)
